FunçõesAnônimas e Arrow Functions

A arrow function é também um tipo de função anônima. Qual a diferença entre elas? A arrow function tem uma estrtutura que ocuta a "function", simplificando a função anôonima convencional. Como? Ela substitui a palara function por "=>"

Quando a função seta possui apenas 1 parâmetro, é possível retirrar o parentese. Exemplo: const triplo = y => { return y * 3; };
